# ห้องทดลองกลยุทธ์ BTC และ ETH

ห้องนี้ใช้ดูว่าราคาบิตคอยน์ (BTC) และอีเธอเรียม (ETH) ในอดีต ถ้าซื้อขายตามกติกาที่คนมักเล่าต่อกัน จะได้เงินมากกว่าการซื้อครั้งเดียวแล้วถือไว้หรือไม่

นี่คืองานวิจัยจากราคาเก่าเท่านั้น

- ไม่มีการซื้อขายจริง
- ไม่ต้องมีบัญชีกระดานเทรด
- ไม่ต้องมี API key
- ไม่มีคำสั่งซื้อขายถูกส่งออกไปไหน
- ผลในอดีตไม่ได้รับประกันว่าอนาคตจะเป็นแบบเดียวกัน และไม่ได้เป็นคำแนะนำให้ซื้อหรือขายเหรียญจริง

ถ้างงคำว่า drawdown, Sharpe หรือ overfitting ให้อ่านหัวข้อ [คำศัพท์](#คำศัพท์ที่ใช้ในรายงาน) ก่อน รายละเอียดผลการทดลองรอบแรกอยู่ใน [JOURNAL.md](JOURNAL.md)

## สรุปสั้น ๆ จากรอบแรก

ข้อมูลรายวันใช้ถึงวันที่ 2026-11-05 (แท่งของวันนี้ยังไม่จบวัน จึงไม่ใส่)

จากกติกาตามตำราที่ยังไม่ได้จูนให้เข้ากับข้อมูลชุดนี้ **มีกลยุทธ์เดียวที่กำไรรวมสูงกว่าซื้อแล้วถือ ทั้งในช่วง 30% ท้ายของข้อมูล และในการทดสอบแบบ walk-forward บนทั้ง BTC และ ETH** คือการถือเหรียญเฉพาะวันที่ราคาปิดอยู่เหนือเส้นค่าเฉลี่ย 200 วัน

กลยุทธ์ซื้อถูกขายแพงแบบ RSI และโบลลินเจอร์แบนด์แพ้ชัด และโบลลินเจอร์ยังขาดทุนทั้งช่วงด้วย รายละเอียด ตัวเลข และสิ่งที่ยังไม่ควรสรุปเร็ว อยู่ใน [JOURNAL.md](JOURNAL.md)

## ดูแดชบอร์ด

หลังรวมเข้าสาขา `main` และเปิด GitHub Pages แล้ว หน้าเว็บอยู่ที่

https://pigger111-hub.github.io/Grok-trading/

หน้านี้เป็นไฟล์ในโฟลเดอร์ `docs/` โทนเรียบ ตัวเลขใหญ่ อ่านบนมือถือได้ การ์ดด้านบนบอกเงินสมมติของแต่ละวิธีว่าเหลือเท่าไหร่จาก 10,000 ดอลลาร์ กำไรหรือขาดทุน ถือเหรียญหรือถือเงินสด และเทียบกับซื้อแล้วถือ เวลาเป็นเวลาประเทศไทย (Asia/Bangkok) ถ้าข้อมูลราคาของเหรียญใดเก่ากว่า 8 ชั่วโมง จะมีป้ายเตือนเล็ก ๆ ที่ชื่อเหรียญนั้น

ถ้าเปิดลิงก์แล้วยังขึ้น 404 ให้ทำตามขั้นตอนด้านล่างหนึ่งครั้ง หลังจากนั้นเวิร์กโฟลว์จะสร้างหน้าใหม่ให้เอง

### เปิด GitHub Pages

1. เปิดรีโปนี้บน GitHub
2. กด **Settings**
3. เมนูซ้ายกด **Pages**
4. ที่ **Build and deployment** ช่อง **Source** เลือก **Deploy from a branch**
5. ช่อง **Branch** เลือก `main` และโฟลเดอร์ `/docs` แล้วกด **Save**
6. รอหนึ่งถึงสองนาที แล้วเปิดลิงก์ด้านบนอีกครั้ง

รีโปสาธารณะใช้ Pages ได้ฟรี ถ้ารีโปเป็นส่วนตัว GitHub อาจให้เปิด Pages ไม่ได้จนกว่าจะเปลี่ยนเป็นสาธารณะ

### เปิด GitHub Actions ถ้าปุ่มยังกดไม่ได้

เวิร์กโฟลว์ชื่อ **paper dashboard** ถูกตั้งให้รันทุก 4 ชั่วโมง มีรอบเก็บตกอีกหนึ่งชั่วโมงถัดไป และกดรันเองได้ มันดึงแท่งที่ปิดแล้วจากแหล่งสาธารณะที่ไม่ใช้ API key (Bitstamp, Bitfinex, Coinbase เฉพาะรายวัน, แล้วสำรองด้วย Kraken หรือ data-api.binance.vision) แล้วต่อสมุดกระดาษและสร้างหน้าแดชบอร์ดใหม่ ถ้าเหรียญใดยังเก่ากว่าแท่งที่ควรปิดแล้ว งานจะล้มเหลวแทนที่จะขึ้นว่าสำเร็จ แล้วคอมมิตกลับเข้าสาขาที่รัน

1. เปิดแท็บ **Actions** ของรีโป
2. ถ้า GitHub ถามให้กด **I understand my workflows, go ahead and enable them**
3. ถ้ายังไม่มีแท็บ หรือรันไม่ได้: **Settings → Actions → General → Actions permissions** เลือก **Allow all actions and reusable workflows** แล้วกด **Save**
4. กลับมาที่แท็บ **Actions** เลือก **paper dashboard** ทางซ้าย แล้วกด **Run workflow** เพื่อไม่ต้องรอถึงรอบ 4 ชั่วโมง

เวิร์กโฟลว์นี้ไม่ส่งคำสั่งซื้อขาย คอมมิตที่มันทำมีแค่ราคา สมุดกระดาษ และไฟล์หน้าเว็บ

## สมุดกระดาษคืออะไร

เป็นการจำลองพอร์ตเริ่ม 10,000 ดอลลาร์ต่อกลยุทธ์ต่อเหรียญ ตั้งแต่วันที่ 2025-01-01 ตามเวลา UTC ใช้ค่าธรรมเนียม 0.10% และ slippage 0.05% เหมือนแบ็กเทสต์ รันซ้ำวันเดิมได้ผลแถวเดิม ไม่มีการส่งออเดอร์

สามกลยุทธ์ที่ถูกจำลอง ไม่ได้เลือกจากตัวที่กำไรทั้งช่วงสูงสุด:

- เส้น 200 วัน เพราะเป็นตัวเดียวที่ชนะซื้อแล้วถือทั้งนอกตัวอย่างและ walk-forward บนทั้งสองเหรียญ
- MACD 12/26/9 เพราะชนะ walk-forward แต่แพ้ช่วง 30% ท้าย และแพ้ง่ายเมื่อค่าธรรมเนียมแพง
- ดอนเชียน 20/10 เพราะกำไรทั้งช่วงของ BTC สูงสุด แต่ช่วงหลังแพ้ เอาไว้ดูว่าจะเป็นอย่างที่การทดสอบนอกตัวอย่างบอกหรือไม่

ซื้อแล้วถือถูกคำนวณคู่กันเพื่อเป็นเส้นเทียบ ไม่ได้นับเป็นกลยุทธ์ที่ถูกเลือก ตัวเลขช่วงสมุดกระดาษถึงวันที่ 2026-11-05 อยู่ใน [JOURNAL.md](JOURNAL.md) สรุปสั้น ๆ คือช่วงนี้ทั้งซื้อแล้วถือและสามกลยุทธ์ยังขาดทุน เส้น 200 วันและดอนเชียนขาดทุนน้อยกว่าซื้อแล้วถือ

ตารางช่วงนอกตัวอย่างอยู่ท้ายหน้าแดชบอร์ด เทียบกรอบรายวัน (1d) กับกรอบ 4 ชั่วโมง (4h) ไม่มีกรอบ 1 ชั่วโมง เพราะสัญญาณหลอกถี่และค่าธรรมเนียม 0.10% บวก slippage 0.05% จะกินกำไรเมื่อซื้อขายบ่อย กลยุทธ์รายวันในสมุดกระดาษเปลี่ยนสถานะได้เฉพาะหลังแท่งวันปิด แม้จ็อบจะตื่นทุก 4 ชั่วโมง ตัวเลข 200 บนกราฟ 4 ชั่วโมงแปลว่า 200 แท่ง (ประมาณ 33 วัน) ไม่ใช่เส้น 200 วัน

ดูบนเครื่องตัวเองก่อนขึ้นเว็บ โดยเปิดโฟลเดอร์ docs เป็นเว็บ แล้วเข้าเบราว์เซอร์ที่ http://127.0.0.1:8000

```bash
python -m http.server 8000 --directory docs
```

หน้านี้ดึงตัวเลขจาก `docs/data/dashboard.json` ต้องมีอินเทอร์เน็ตตอนเปิดหน้า เพราะกราฟโหลดไลบรารี Lightweight Charts จากเน็ต

## คำศัพท์ที่ใช้ในรายงาน

**ซื้อแล้วถือ (buy and hold)** คือเอาเงินทั้งหมดซื้อเหรียญที่จุดเริ่มของช่วงที่ทดสอบ แล้วไม่ขายจนจบช่วง เป็นตัวเทียบหลัก เพราะเป็นสิ่งที่คนทำได้โดยไม่ต้องมีสัญญาณเลย

**ผลตอบแทนรวม** คือเงินตอนจบเทียบกับเงินตอนเริ่ม เช่น เริ่ม 10,000 แล้วจบ 15,000 ผลตอบแทนรวมคือ 50%

**ทบต้นต่อปี (CAGR)** คือถ้าการโตนั้นกระจายเรียบทุกปี จะได้ประมาณปีละกี่เปอร์เซ็นต์ ใช้เทียบช่วงเวลาที่ยาวไม่เท่ากันได้ดีกว่าการดูผลตอบแทนรวมก้อนเดียว

**Drawdown หรือการขาดทุนจากจุดสูงสุด** คือพอร์ตเคยร่วงจากจุดที่สูงที่สุดลงมาแค่ไหน ตัวอย่าง: พอร์ตขึ้นไป 15,000 แล้วร่วงเหลือ 9,000 การขาดทุนรอบนั้นคือ 9,000 ÷ 15,000 − 1 = −40% **การขาดทุนสูงสุด (max drawdown)** คือรอบที่เจ็บที่สุดตลอดการทดสอบ บิตคอยน์ที่ซื้อแล้วถือเคยร่วงจากจุดสูงสุดเกิน 80% ทั้งที่คนที่ถือจนจบช่วงยาวได้เงินก้อนใหญ่ นั่นแปลว่าทางระหว่างทางโหดมาก

**Sharpe** คือกำไรเฉลี่ยเทียบกับความแกว่งของพอร์ต ยิ่งสูงยิ่งแปลว่าได้ผลตอบแทนมากเมื่อเทียบกับแรงเหวี่ยง ที่นี่คิดดอกเบี้ยเงินสดเป็น 0 และใช้ 365 วันต่อปี เพราะคริปโตเทรดทุกวัน รวมเสาร์อาทิตย์ อย่าเอาตัวเลขนี้ไปเทียบกับ Sharpe ของหุ้นที่เขาคิดคนละแบบ ใช้เทียบกลยุทธ์ในห้องนี้ด้วยกันเท่านั้น

**อัตราชนะ** คือสัดส่วนของรอบที่ขายแล้วได้กำไร หรือถ้ายังถืออยู่ตอนจบ ก็ตีราคาตามราคาปิดวันสุดท้าย อัตราชนะสูงไม่ได้แปลว่าได้เงินเยอะ กลยุทธ์ตามเทรนด์มักแพ้บ่อยเป็นก๊อกเล็ก ๆ แล้วได้กำไรก้อนใหญ่ไม่กี่ครั้ง

**สัดส่วนวันที่ถือ** คือกี่เปอร์เซ็นต์ของวันทั้งหมดที่พอร์ตถือเหรียญอยู่ ที่เหลือคือถือเงินสด เงินสดในห้องนี้ได้ดอกเบี้ย 0%

**ในตัวอย่าง (in-sample)** คือ 70% แรกของประวัติ ใช้ดูว่ากติกาเป็นอย่างไรในอดีตช่วงต้น

**นอกตัวอย่าง (out-of-sample)** คือ 30% ท้าย ซึ่งไม่ได้ถูกใช้ในการเลือกกติตามาตรฐาน ถ้ากลยุทธ์ดูดีเฉพาะช่วงแรก แล้วช่วงท้ายพัง แสดงว่ามันอาจแค่ท่องอดีตช่วงต้น

**Walk-forward** คือวิธีเข้มกว่านั้นอีก: ใช้ 2 ปีย้อนหลังเลือกค่าพารามิเตอร์ แล้วนำค่านั้นไปเทรดปีถัดไปเท่านั้น จากนั้นเลื่อนหน้าต่างไปเรื่อย ๆ แล้วเอาผลแต่ละปีมาต่อกัน ปีที่ใช้เลือกค่าจะไม่ถูกนับเป็นผลสอบ

**Overfitting หรือการท่องข้อสอบ** คือการลองค่าหลายแบบแล้วเลือกค่าที่ดูสวยบนข้อมูลชุดเดียวกับที่เอามารายงาน ตัวเลขจะดูดีเกินจริง พอเจอราคาช่วงใหม่มักพัง ห้องนี้มีแถวที่ติดป้ายไว้ชัดว่า "เลือกพารามิเตอร์จากข้อมูลชุดเดียวกัน" แถวนั้นห้ามถือเป็นผลจริง

**Look-ahead bias หรือการแอบดูอนาคต** คือการใช้ราคาของวันพรุ่งนี้มาตัดสินใจซื้อวันนี้ โปรแกรมนี้ไม่ทำแบบนั้น สัญญาณใช้ราคาปิดของวันนี้ได้ แล้วไปซื้อหรือขายที่ราคาเปิดของวันถัดไป

## สิ่งที่โปรแกรมสมมติไว้

เปลี่ยนตัวเลขพวกนี้ได้ที่ไฟล์ `crypto_lab/assumptions.py`

- เงินเริ่มต้นสมมติ 10,000 ดอลลาร์ต่อหนึ่งการทดสอบ แต่ละช่วงในตารางเริ่มเงินก้อนใหม่ ไม่ได้ยกพอร์ตจากช่วงก่อนมา
- ซื้อได้เต็มจำนวน หรือถือเงินสดเท่านั้น ไม่ขายชอร์ต ไม่ใช้เลเวอเรจ
- ค่าธรรมเนียม 0.10% ของมูลค่าที่ซื้อหรือขายแต่ละครั้ง ใกล้เคียงค่าธรรมเนียมสปอตมาตรฐานที่หลายกระดานประกาศไว้ก่อนมีส่วนลด
- Slippage อีก 0.05% เป็นการสมมติว่าซื้อได้แพงกว่าราคาเปิดนิดหนึ่ง และขายได้ถูกกว่าราคาเปิดนิดหนึ่ง ไม่ใช่ตัวเลขที่วัดจากตลาดรายวัน
- เงินสดไม่ได้ดอกเบี้ย และยังไม่หักภาษี
- แต่ละช่วงทดสอบจบด้วยการตีราคาเหรียญที่ยังถืออยู่ตามราคาปิดวันสุดท้าย โดยไม่คิดค่าธรรมเนียมขาย เพราะยังไม่ได้ขายจริง

มีตารางเพิ่มที่ลองค่าธรรมเนียม 0% และ 0.50% เพื่อดูว่าข้อสรุปพังง่ายแค่ไหนถ้าค่าธรรมเนียมแพงขึ้น

ไฟล์ราคาอยู่ใน `data/cache/` ขนาดรวมไม่ถึง 1 เมกะไบต์ รันคำสั่งดาวน์โหลดซ้ำเมื่อไรก็ได้อนาคตจะต่อให้ถึงวันล่าสุดที่จบแล้ว

## ติดตั้งและรันบนคอมพิวเตอร์ตัวเอง

ต้องมีอินเทอร์เน็ตตอนดาวน์โหลดราคา ใช้ Python 3.11 ขึ้นไป ห้องนี้ทดสอบกับ Python 3.12

### 1. ติดตั้ง Python

1. เปิด https://www.python.org/downloads/
2. ดาวน์โหลดตัวติดตั้งของระบบที่ใช้
3. บน Windows ให้ติ๊กช่อง **Add python.exe to PATH** ก่อนกดติดตั้ง
4. เปิดเทอร์มินัลแล้วเช็คว่าใช้ได้
   - Windows: เปิดแอปชื่อ Command Prompt แล้วพิมพ์ `py --version`
   - Mac: เปิดแอปชื่อ Terminal แล้วพิมพ์ `python3 --version`
   - Linux: เปิดเทอร์มินัลแล้วพิมพ์ `python3 --version`

ถ้าเห็นเลขเวอร์ชันขึ้นต้นด้วย 3.11 หรือสูงกว่า ใช้ต่อได้

### 2. เข้าโฟลเดอร์โปรเจกต์

สมมติว่าแตกไฟล์หรือโคลนไว้ที่โฟลเดอร์นี้แล้ว ให้ใช้คำสั่ง `cd` เข้าไป ตัวอย่างบน Mac หรือ Linux

```bash
cd ~/Grok-trading
```

บน Windows ตัวอย่าง

```bat
cd %USERPROFILE%\Grok-trading
```

### 3. สร้างที่อยู่ของไลบรารี แล้วติดตั้งของที่ต้องใช้

Mac หรือ Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Windows

```bat
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

ถ้าบรรทัด `python` ใช้ไม่ได้ ให้ลอง `python3` หรือ `py` แทนทุกที่ด้านล่าง เวลาเปิดเทอร์มินัลใหม่ ต้องสั่ง `source .venv/bin/activate` หรือ `.venv\Scripts\activate` อีกครั้งก่อนรัน

### 4. รันทุกอย่างด้วยคำสั่งเดียว

```bash
python scripts/run_all.py
```

คำสั่งนี้จะดาวน์โหลดราคาล่าสุด ทดสอบทุกกลยุทธ์ กวาดพารามิเตอร์ เขียนรายงาน QuantStats ต่อสมุดกระดาษ และสร้างแดชบอร์ด ใช้เวลาประมาณหนึ่งถึงสองนาทีถ้าเน็ตปกติ เมื่อจบจะมี

- `results/summary.md` และ `results/summary.csv` ตารางตัวเลข
- `results/folds.csv` ค่าที่ walk-forward เลือกในแต่ละปี
- `results/charts/` กราฟเส้นเงินของแต่ละการรัน มาตราส่วนเป็นล็อก เพื่อให้ช่วงราคาถูกในอดีตยังอ่านได้
- `data/QUALITY.md` รายงานคุณภาพข้อมูลที่อัปเดตใหม่
- `data/lab.sqlite` ฐานข้อมูลผลแบ็กเทสต์ ผลกวาดพารามิเตอร์ และสมุดกระดาษ
- `docs/index.html` แดชบอร์ด อ่านคู่กับ `docs/dashboard.css`, `docs/dashboard.js`, และ `docs/data/dashboard.json`
- `docs/tearsheets/` รายงาน QuantStats เทียบซื้อแล้วถือ

อยากอัปเดตเฉพาะสมุดกระดาษกับหน้าเว็บ โดยไม่รันการทดสอบทั้งก้อนใหม่

```bash
python scripts/update_lab.py
```
- ตารางใน `JOURNAL.md` ถูกใส่ใหม่ระหว่างเครื่องหมาย `RESULTS` และ `COSTS` ข้อความอธิบายที่เขียนไว้รอบ ๆ จะไม่ถูกลบ

ถ้าดาวน์โหลดพัง ให้เช็คอินเทอร์เน็ตแล้วรันคำสั่งเดิมอีกครั้ง โปรแกรมจะไม่เขียนทับไฟล์ราคาเก่าด้วยข้อมูลที่โหลดไม่ครบ

แยกขั้นได้ ถ้าอยากโหลดอย่างเดียวหรือทดสอบอย่างเดียว

```bash
python scripts/download_data.py
python scripts/run_backtests.py
```

คนที่อยากเช็คว่าเครื่องคิดเลขของแบ็กเทสต์ยังตรงอยู่ รัน

```bash
python -m pytest
```

ไม่จำเป็นต้องรันข้อนี้ถ้าแค่อยากดูผลกลยุทธ์

- `crypto_lab/data.py` ดาวน์โหลดและตรวจราคา
- `crypto_lab/indicators.py` เส้นค่าเฉลี่ย RSI MACD โบลลินเจอร์ ดอนเชียน
- `crypto_lab/strategies.py` กติกาแต่ละกลยุทธ์ พร้อมที่มาของคำกล่าวอ้าง
- `crypto_lab/engine.py` เครื่องแบ็กเทสต์ ซื้อที่ราคาเปิดวันถัดไป
- `crypto_lab/walkforward.py` เลือกพารามิเตอร์จากอดีตอย่างเดียว
- `crypto_lab/research.py` รันทุกการทดลอง เขียนตารางและกราฟ
- `crypto_lab/assumptions.py` ค่าธรรมเนียม slippage ความยาวหน้าต่างทดสอบ และวันเริ่มสมุดกระดาษ
- `crypto_lab/sweep.py` กวาดพารามิเตอร์ด้วยเครื่องทดสอบเดิม และตรวจปลายทางกับ VectorBT
- `crypto_lab/paper.py` สมุดกระดาษที่รันซ้ำได้
- `crypto_lab/market.py` ต่อแท่งล่าสุดจากแหล่งสาธารณะแบบไม่ใช้กุญแจ และทำให้งานล้มเหลวถ้าราคาเก่า
- `crypto_lab/dashboard.py` หน้าเว็บนิ่ง
- `JOURNAL.md` บันทึกการทดลองภาษาไทย และหัวข้อ `NEXT_STEPS` สำหรับรอบถัดไป
- `.github/workflows/paper-dashboard.yml` งานอัตโนมัติทุก 4 ชั่วโมง

## ให้คนหรือเอเจนต์ทำรอบถัดไป

1. อ่าน `JOURNAL.md` ทั้งไฟล์ โดยเฉพาะตารางล่าสุดและหัวข้อ `NEXT_STEPS`
2. ทำการทดลองข้อแรกใน `NEXT_STEPS` เพียงข้อเดียว
3. รัน `python scripts/run_all.py`
4. เพิ่มบันทึกการทดลองใหม่ต่อท้ายของเก่า อย่าลบรอบก่อน
5. อัปเดต `NEXT_STEPS` ให้ชี้ไปที่ความคิดถัดไปหนึ่งข้อ พร้อมบอกว่าควรทำถ้าผลเป็นแบบไหน และควรหยุดถ้าผลเป็นแบบไหน
